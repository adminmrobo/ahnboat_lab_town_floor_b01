# floor_b01

Ahn Lab Town 지하 1층 **서버실**의 랙 데이터 저장소입니다. `servers.csv`만 고치면 랩타운 서버실에 반영됩니다.

- 기본 열 순서: 카테고리 / 제목 / 내용소개 / 해시태그 / 생성일 / 비고
- 카테고리가 처음 나온 순서대로 RACK 01~10에 배정됩니다 (최대 10개).
- 엑셀에서 고친 뒤 "CSV"로 저장해서 같은 이름으로 덮어쓰면 됩니다. 한글 엑셀 기본 형식과 UTF-8 모두 읽습니다.
- 랩타운의 `config.json` → `SERVER_CSV_URL`에 이 파일의 Raw 주소가 들어 있습니다.

## 번역 열 (선택)
`원래 열 이름_언어코드` 열을 추가하면 그 언어로 볼 때 해당 칸이 표시되고, 비어 있으면 한국어가 보입니다.

- 언어코드: `en` · `zh` · `ja` · `uz` · `ru`
- 예: `카테고리_en`, `제목_en`, `내용소개_en`, `해시태그_en`, `비고_en`
- 카테고리 번역은 그 카테고리의 첫 줄에만 적어도 랙 이름에 적용됩니다.
